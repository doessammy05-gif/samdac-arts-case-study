# Samdac Arts: Digital Transformation Case Study

## Project Overview
This repository serves as the technical archive for the **Samdac Arts** initiative, presented at the 10th DeKUT STIE Conference. The project focuses on bridging the digital divide for student-led micro-enterprises by providing affordable, high-performance landing pages and AI automation.

## Technical Stack
- **Frontend:** Next.js 14+, Tailwind CSS
- **Infrastructure:** Vercel Deployment
- **Automation:** Custom AI Workflows for Lead Capture
- **Design Philosophy:** Conversion Rate Optimization (CRO) for micro-budgets

## Research Focus
The core objective was to analyze the transition of campus businesses from social-media-only presence to structured web architectures. Key metrics tracked include:
- Perceived Professional Credibility
- Lead Generation Volume
- Operational Time Reduction via AI Automation

## Dataset & Metrics
The `/metrics` directory contains a summarized dataset comparing performance before and after the implementation of the Samdac Arts framework.
